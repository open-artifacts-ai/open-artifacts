When to upgrade

The free plan's limits reset every day at 00:00 UTC. A meter turns amber at 80% and red at 95%. Once a limit is reached, writes fail until the reset.

If one turns red most days, move the account to Workers Paid in the Cloudflare dashboard. Nothing in Open Artifacts changes, and no redeploy is needed.

  • Worker requests grow with views, uploads, and agent calls.
  • D1 grows with library browsing, search, and publishing.
  • Durable Objects grow with live pages: polls, checklists, shared data.

Connect Cloudflare analytics to see usage

Open Artifacts reads today's numbers from Cloudflare's GraphQL Analytics API. It needs a read-only token, stored as the ANALYTICS_TOKEN Worker secret. Everything else works without it.

  1. Create an API token

    In the Cloudflare dashboard, open My Profile → API Tokens and choose Create Token → Custom token.

  2. Give it one permission

    Add the permission below, and under Account Resources include only this account.

    AccountAccount AnalyticsRead
  3. Store it as a Worker secret

    From your Open Artifacts checkout, run this and paste the token when asked.

    npx wrangler secret put ANALYTICS_TOKEN
  4. Reload this page

    Usage appears right away. The token is never shown in the dashboard again.
