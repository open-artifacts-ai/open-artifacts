Q4 data migration plan

Move the orders and billing tables from the legacy Postgres 11 cluster to the new Aurora cluster with no more than 5 minutes of write downtime, finishing before the December freeze.

Scope

Three schemas move this quarter. Analytics replicas stay on the old cluster until January and read through a foreign data wrapper in the meantime.

  • orders: 1.8 TB, 412M rows, highest write volume
  • billing: 240 GB, includes the Stripe event ledger
  • catalog: 36 GB, read-heavy, safe to move first

Cutover procedure

Run from the bastion host. The script pauses writers, waits for replication lag to reach zero, then flips the connection string in the config service.
