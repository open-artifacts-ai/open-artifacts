MCP server

Any agent that supports MCP OAuth connects with this URL alone. You approve it in the browser the first time.

Streamable HTTP

Connect an agent

Paste into your agent's config. Agents without OAuth support can use a personal access token instead.

Run once in a terminal. Claude Code opens your browser to approve the connection on first use.

claude mcp add --transport http open-artifacts https://artifacts.northwind.dev/mcp

Add to ~/.codex/config.toml, then sign in.

[mcp_servers.open-artifacts]
url = "https://artifacts.northwind.dev/mcp"
codex mcp login open-artifacts

Add to ~/.cursor/mcp.json (or .cursor/mcp.json in a project).

{
  "mcpServers": {
    "open-artifacts": {
      "url": "https://artifacts.northwind.dev/mcp"
    }
  }
}

Add to opencode.json in your project or ~/.config/opencode/.

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "open-artifacts": {
      "type": "remote",
      "url": "https://artifacts.northwind.dev/mcp"
    }
  }
}

Any MCP client. Use OAuth if it's supported; otherwise send a personal access token as a Bearer header.

# Transport: Streamable HTTP

# or, without OAuth:
Authorization: Bearer oa_pat_…
